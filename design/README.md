# Design explorations

Visual design work that isn't yet part of the app. Nothing in this
directory ships; `src/css/styles.css` remains the live styling until a
direction is chosen and folded in.

- `ui-directions-2026-07.html` — four visual directions for a more
  sophisticated UI (Morning Linen / Field Notes / Lantern / Pebble),
  each applied to the feed and an interview card, with a side-by-side
  comparison and recommendation. Open directly in a browser (fonts load
  from Google Fonts). Summary and per-direction tokens in
  `ui-directions-2026-07.md`.

- `landing-brief-2026-09.md` — the brief the three September 2026
  landing directions were drawn against (job of the page, goals
  judged, voice rules, fixed Morning Linen tokens, constraints).
- `landing-directions-2026-09.md` — those three directions judged
  holds/partly/fails against the design-spec goals, written before
  any preference was voiced (U10 step 5), with the measurement method
  and the recommendation. The directions themselves live in
  `src/landing/` because they are reviewed live on a workshop stack;
  the deploy drops that directory from a prod bundle.
