# Design explorations

Visual design work that isn't yet part of the app. Nothing in this
directory ships; `src/css/styles.css` remains the live styling until a
direction is chosen and folded in.

- `ui-directions-2026-07.html` — four visual directions for a more
  sophisticated UI (Morning Linen / Field Notes / Lantern / Pebble),
  each applied to the feed and an interview card, with a side-by-side
  comparison and recommendation. Open directly in a browser (fonts load
  from Google Fonts). Summary and per-direction tokens in
  `ui-directions-2026-07.md`.
